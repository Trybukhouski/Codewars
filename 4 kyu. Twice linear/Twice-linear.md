## Суть задачи

Представьте, что у нас есть бесконечный числовой ряд (назовем его $u$), который создается по строгому правилу:

1. Всё начинается с единицы. Самое первое число в нашем ряду — это всегда 1.
2. Каждое число $x$, которое уже попало в наш ряд, должно «породить» два новых числа по двум разным формулам:
   - Конвейер №1: Умножаем число на 2 и прибавляем 1 $\rightarrow$ $(2 \cdot x + 1)$
   - Конвейер №2: Умножаем число на 3 и прибавляем 1 $\rightarrow$ $(3 \cdot x + 1)$
   - Никаких других чисел, кроме полученных этими способами, в ряду быть не может.

## Как это выглядит на практике:

- Начинаем с 1:
  - Она создает: $2 \cdot 1 + 1 = \mathbf{3}$ и $3 \cdot 1 + 1 = \mathbf{4}$.
- Теперь очередь 3:
  - Она создает: $2 \cdot 3 + 1 = \mathbf{7}$ и $3 \cdot 3 + 1 = \mathbf{10}$.
- Теперь очередь 4:
  - Она создает: $2 \cdot 4 + 1 = \mathbf{9}$ и $3 \cdot 4 + 1 = \mathbf{13}$.
- ...и так далее до бесконечности.

Если мы соберем все созданные числа вместе, отсортируем их по возрастанию и удалим все повторения (дубликаты), то получим вот такую красивую последовательность:

```
u = [1, 3, 4, 7, 9, 10, 13, 15, 19, 21, 22, 27, ...]
```

## Ваша задача

Напишите функцию `dblLinear(n)`, которая принимает индекс n и возвращает число, стоящее на этом месте в нашей отсортированной последовательности (индексация элементов начинается с нуля).

## Примеры работы функции

- `dblLinear(0)` должно вернуть `1` (самый первый элемент)
- `dblLinear(3)` должно вернуть `7` (элемент под индексом 3)
- `dblLinear(10)` должно вернуть `22`

## Важное примечание

Обратите особое внимание на эффективность вашего алгоритма. В тестах значение `n` может доходить до `100 000`.Если вы будете просто складывать числа в кучу, а потом каждый раз удалять дубликаты и сортировать массив заново через стандартный метод `.sort()`, ваша программа зависнет и не пройдет тесты по времени.

# Решение

## Шаг 1. Инициализация основы

Создаем каркас функции:

- массив, где уже лежит стартовое число 1
- два указателя (индекса), которые в самом начале смотрят на этот самый первый элемент (индекс 0).

```
function dblLinear(n) {
  const u = [1];
  let pt2 = 0;
  let pt3 = 0;
}
```

## Шаг 2. Создание главного цикла

Создаем цикл, чтобы генерировать элементы один за другим до тех пор, пока мы не заполним массив до индекса n. Поскольку индексация идет с нуля, массив должен накопить длину хотя бы n + 1.

```
while (u.length <= n) {}
```

## Шаг 3. Расчет кандидатов на текущем шаге

Внутри цикла нам нужно смотреть, на какие числа сейчас указывают наши «пальцы» pt2 и pt3. Для этого мы рассчитываем для них их формулы.

```
const next2 = 2 * u[pt2] + 1;
const next3 = 3 * u[pt3] + 1;
```

## Шаг 4. Выбор меньшего и сдвиг указателей (Логика сравнения)

Теперь нам нужно выбрать, какой из кандидатов меньше. Тот, кто меньше, отправляется в массив первым, а его указатель делает шаг вперед.

Если кандидаты равны, мы добавляем число один раз, но сдвигаем оба указателя (это защищает нас от дубликатов).

```
if (next2 < next3) {
  u.push(next2);
  pt2++;
} else if (next3 < next2) {
  u.push(next3);
  pt3++;
} else {
  u.push(next2);
  pt2++;
  pt3++;
}
```

## Шаг 5. Финал и возврат значения

Как только цикл завершился, наш массив гарантированно заполнен правильными числами по возрастанию вплоть до нужного места. Нам остается только забрать элемент.

```
return u[n];
```

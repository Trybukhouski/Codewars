### Для тимлидов и рекрутеров

Этот проект демонстрирует мой подход к написанию кода и решению алгоритмических задач.

### Для разработчиков

Если вы ищете решение конкретной задачи или хотите посмотреть другой взгляд на алгоритм. Внутри каждой папки лежит не просто код, а **пошаговый разбор логики**.
